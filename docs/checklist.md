# 수동 검수 체크리스트

## 공통 (모든 페이지)
- [ ] 헤더/푸터/GNB 메뉴 링크가 모두 올바른 페이지로 이동하는가 (빈 `#` 링크 없음)
- [ ] 현재 메뉴 활성 표시(active)가 정확한가
- [ ] 로고 클릭 시 홈으로 이동하는가
- [ ] 폰트/색상/여백이 페이지 간 일관적인가
- [ ] 이미지 비율이 찌그러지거나 잘리지 않는가, 저해상도 이미지가 없는가
- [ ] 모바일(390px)/태블릿(768px)/데스크톱(1440px)에서 레이아웃 깨짐·가로 스크롤 없음
- [ ] 햄버거 메뉴 열기/닫기, 서브메뉴 동작
- [ ] 브라우저 탭 제목(title), 파비콘, OG 메타
- [ ] 콘솔 오류 / 404 리소스 없음
- [ ] 더미 텍스트(샘플, lorem) 및 "준비중" 페이지 여부

## 홈
- [ ] 메인 비주얼/슬라이드 자동 재생, 좌우 버튼, 인디케이터
- [ ] 예배 시간/오시는 길 등 핵심 정보 정확성
- [ ] 최신 게시물/설교 영상 위젯이 실제 최신 데이터인가
- [ ] 팝업/배너 닫기 및 "오늘 하루 보지 않기" 동작

## 교회 소개 / 오시는 길
- [ ] 지도(카카오/네이버/구글) 정상 로딩, 마커 위치 정확
- [ ] 주소·전화번호 클릭 시 tel: 동작(모바일)

## 설교 / 영상
- [ ] 유튜브 임베드 재생, 목록 페이징, 검색
- [ ] 썸네일 누락 없음

## 게시판 (공지, 자유, 갤러리, 자료실)
- [ ] 목록 → 상세 → 목록 복귀 시 페이지 번호/검색 조건 유지
- [ ] 검색(제목/내용/작성자), 페이징, 정렬
- [ ] 첨부파일 다운로드, 이미지 뷰어
- [ ] 비밀글/권한 없는 글 접근 시 안내
- [ ] 댓글 작성/수정/삭제 (권한)
- [ ] 글쓰기 폼 유효성 검사(필수값, 길이), 에디터 동작, 이미지 업로드

## 회원 / 로그인
- [ ] 로그인 실패 시 메시지, 성공 시 리다이렉트
- [ ] 아이디/비밀번호 찾기
- [ ] 회원가입 유효성(휴대폰 형식, 중복 체크, 약관 동의)
- [ ] 로그아웃 후 보호 페이지 접근 차단
- [ ] 세션 만료 처리

## 관리자
- [ ] 비관리자 계정/비로그인으로 관리자 URL 직접 접근 시 차단
- [ ] 메뉴/게시판/회원/팝업/배너 관리 CRUD (테스트 데이터 생성 후 반드시 삭제)
- [ ] 목록 필터·검색·엑셀 다운로드
- [ ] 입력 폼 XSS/스크립트 입력 시 이스케이프 처리
- [ ] 권한 변경 즉시 반영

## 성능 / 기타
- [ ] 첫 화면 로딩 3초 이내, 이미지 lazy loading
- [ ] HTTPS 강제(http → https 리다이렉트), mixed content 없음
- [ ] www / non-www 통일
- [ ] 404 페이지 디자인 및 홈으로 돌아가기 링크
