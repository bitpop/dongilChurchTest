## 상세

### 1. 설교 필터 '주일'·'수요'가 항상 0건 (높음)
- 재현: /worship/sermons → '주일' 클릭 → "조건에 맞는 설교가 없어요". 실제 목록에는 주일예배 설교 49건 이상 존재.
- 원인(확인): 화면은 `GET /api/sermons?serviceType=주일` 을 호출하지만 데이터의 serviceType 값은 `주일예배` 이고 API 는 완전 일치로 필터함.
  - `GET /api/sermons?serviceType=주일예배` → 20건, `?serviceType=주일` → 0건.
- 영향: 필터 기능 전체가 무용. 모바일·데스크톱 동일.
- 제안: 프론트에서 '주일'→'주일예배', '수요'→'수요예배' 로 매핑하거나, API 를 prefix/contains 매칭으로 변경. '수요' 설교 데이터가 실제로 없다면 필터 버튼 자체를 숨기는 것도 고려.
- 증빙: `docs/evidence/01_sermon_filter_sunday_empty.png`

### 2. 예배안내 표 구조 (중간)
- 페이지: /worship/time (데스크톱 표 / 모바일 카드 동일)
- 증상: 다음 항목이 독립 행으로 표시되어 '예배명' 열에 시간이, '시간'·'장소' 열이 비어 있음.
  - 정기예배: "2부 오전 11시" (주일예배의 2부), "토 - 살렘어린이집"(중보기도 장소), "금요철야 오후 8시"(사무엘학교)
  - 교회학교: 초등부·중등부·고등부의 "오전 10시 (소그룹)" 행
- 원인(확인): 관리자 콘솔 > 콘텐츠 > 예배안내 표 편집기에서 "2부 오전 11시" 등이 **예배명 열에 별도 행**으로 입력되어 있음(시간·장소 열 비어 있음). 편집기가 셀당 한 줄만 지원해 다중 시간을 넣을 방법이 없어 보임.
- 제안: (단기) 행을 "주일예배 1부 / 주일예배 2부 / 초등부 예배 / 초등부 소그룹" 식으로 예배명 열을 채워 재입력. (중기) 표 편집기 셀에 줄바꿈 지원 또는 '시간' 열 다중 값 지원. 데스크톱 표가 화면 폭의 1/3만 사용해 빈 공간이 큰 점도 함께 조정 권장.
- 증빙: `reports/routes-admin/manage_contents_desktop.png` (관리자 화면이라 저장소에는 미포함)
- 증빙: `docs/evidence/02_worship_time_table_desktop.png`, `docs/evidence/02_worship_time_mobile.png`

### 3. 섬기는 분들 빈 화면 (중간)
- /about/pastors, 전체 메뉴·교회소개 버튼에서 진입 가능. `GET /api/staff` → `[]`, `/api/staff-groups` → `[]`.
- 공개 메뉴에 노출된 페이지가 비어 있으므로 데이터 등록 또는 메뉴에서 임시 숨김 필요.

### 4. 테스트 게시물 공개 노출 (중간)
- /heritage/wishes 목록 1번 글 "테스트 / 테스트" (슈퍼관리자 계정 작성, 2026.10.21). 관리자 화면에서 삭제 권장.

### 5. 모든 경로 200 응답 (중간)
- `curl -I https://dongilchurch.com/asdf` → 200 text/html (index.html). `/robots.txt`, `/sitemap.xml`, `/favicon.ico` 도 HTML 5,003B 반환.
- 영향: 검색엔진 soft-404 처리, robots 지시 불가, 브라우저 파비콘 요청에 HTML 응답(파비콘 자체는 `<link rel=icon href=favicon.png>` 로 정상 표시됨).
- 제안: `/robots.txt`, `/sitemap.xml` 실제 파일 제공, `/favicon.ico` 제공 또는 404, 가능하면 미존재 경로는 404 상태코드로 SSR 응답.

### 7. 루트(/)와 /home 이중 구조 (중간, 디자인/UX)
- `/` 는 배너+바로가기+전체메뉴(앱 허브형, 데스크톱에서도 폭 600px 중앙 정렬, GNB 없음). `/home` 은 GNB 포함 일반 홈.
- 로고 클릭·GNB 는 /home 으로, 로그인 완료·'홈' 탭은 `/` 로 보내 사용자가 두 가지 '홈'을 오가게 됨. 허브에 있는 "홈페이지 바로가기" 버튼은 홈페이지 안에서 홈페이지로 가는 버튼이라 혼란.
- 제안: 데스크톱 접속 시 `/` → `/home` 리다이렉트(또는 반대로 통일), 모바일만 허브 유지.
- 증빙: `docs/evidence/07_root_hub_desktop.png`, `docs/evidence/07_home_desktop.png`

### 8. 접근성 (중간)
- Flutter 시맨틱 트리 기준(스크린리더가 읽는 정보):
  - 데스크톱 헤더의 GNB(예배/강의/…)·로고·검색·로그인 버튼이 트리에 없음 → 키보드/스크린리더로 메뉴 이동 불가.
  - 로그인 입력란(tel/password)에 접근 가능한 이름 없음, 로그인 실패 메시지도 트리에 미노출.
- 제안: `Semantics(label:)`/`semanticsLabel` 추가, 입력란에 `InputDecoration.labelText` 또는 semantics label.

### 9. 모바일 하단 탭바 사라짐 (낮음)
- `/`, `/home` 에서는 홈·예배·강의·소그룹·전체 탭이 있으나 설교 목록 등으로 이동하면 사라지고 상단 ←와 햄버거만 남음. 탭형 내비게이션을 쓴다면 주요 페이지에서 유지 권장.

### 10~12. 콘텐츠 품질 (낮음)
- /about 본문: "교회를 세우고자농가 마당에서", "당진 산골 에", "차 별화된 방과 후학교", "담임목사 이 수 훈" (CMS `contents.about` 수정).
- /ministry: 주일의료봉사·폴스웨이·감골마을협동조합이 같은 사진, 시립마을도서관·따뜻한 안내소·OJ베이커리가 같은 요약문. 영아부~청년부 항목은 이미지 없음.
- /press 첫 카드 썸네일 없음.

### 13~15. 디자인 세부 (낮음)
- 모바일 허브 배너 2번째 슬라이드(1600×800)에서 우측 텍스트가 화살표 버튼과 겹침. 배너 이미지 안전 여백 확보 또는 화살표를 이미지 밖으로.
- 주보 상세(데스크톱): 주보 1면이 약 170px 폭으로 표시. 데스크톱은 최소 600px 이상으로 바로 읽히게 하는 것이 자연스러움. 갤러리 앨범 상세도 110px 썸네일만 나열.
- 없는 콘텐츠 처리: 설교(`/worship/sermons/999999`)는 브레드크럼·제목 유지, 교우소식(`/member-news/999999`)은 오류 문구만. 공통 오류 컴포넌트로 통일 권장.

### 16~18. 서버 설정 (낮음)
- `https://www.dongilchurch.com/` 200 (리다이렉트 없음) → 301 로 non-www 통일 권장.
- `/api/*` 응답에 `strict-transport-security` 헤더 2개(`includeSubDomains` 유무가 다름) → 하나로.
- 공개 목록 페이지 HTML 에 `<!--SSR:HEAD-->` 마커와 "주차 6~7, Q6" 등 내부 작업 메모 주석이 그대로 전송됨. 상세 페이지(설교·교우소식)는 OG/title 치환이 정상 동작함.

### 19. 세션 보안 동작 (정보)
- 저장해 둔 refresh 토큰을 다시 사용하자 `POST /api/auth/refresh` → 401 "보안을 위해 모든 기기에서 로그아웃되었습니다" 가 반환되고, 같은 계정의 다른 기기 세션(목록상 "web · Chrome · macOS")도 함께 로그아웃됨.
- 토큰 재사용 탐지는 올바른 보안 설계이나, 사용자가 갑자기 로그아웃되는 이유를 알 수 없으므로 알림/안내 문구 노출 권장.
- **주의**: 이 검수 과정에서 검수에 사용한 관리자 계정의 기존 기기 세션(macOS Chrome)이 함께 로그아웃되었습니다. 해당 브라우저에서 다시 로그인이 필요합니다.

### 20~21. 관리자·내 정보 (낮음)
- 멤버 관리 명부에 "홍길동 / 개별 등록 / 차단" 테스트 항목이 남아 있음(총 7명 중). 운영 데이터와 섞이지 않도록 삭제 권장.
- 내 정보 > 로그인 기기: 기기 이름 자체에 마지막 사용 시각이 들어가 "웹 브라우저 · Chrome · Linux (마지막 사용 2026. 11. 2 15:51)" 로 표시되고, 아래 줄에 "마지막 사용 방금" 이 다시 표시됨. 기기명은 "웹 브라우저 · Chrome · Linux" 로만 저장하고 시각은 별도 필드로 표시 권장.
- 관리자 콘솔 전반(대시보드·멤버·권한·설교·콘텐츠·배너·주보 관리)은 데스크톱/모바일 모두 레이아웃 깨짐이나 오류 없이 렌더링됨. 등록·수정·삭제 동작은 운영 데이터 보호를 위해 실행하지 않음.

## 정상 확인 항목
- 로그인: 잘못된 비밀번호 시 "휴대폰번호 또는 비밀번호가 올바르지 않아요 (4번 더 틀리면 10분 동안 잠겨요)" 표시, 정상 로그인 후 `/` 이동. 잠금 정책 동작.
